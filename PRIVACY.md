# Privacy Policy (Local-first)

- Prompt content is stored locally on your device (IndexedDB).
- The extension does not send your prompt content to any server by default.
- If you enable a remote embedding provider, the extension may send:
  - prompt body text for embedding
  - query text for embedding
  This is strictly opt-in and can be disabled anytime.
- No telemetry is collected by default.

Data deletion:
- You can delete individual prompts or wipe all data from settings.
